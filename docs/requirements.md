友人同士で気軽に写真と日常のキャプションを共有できる、インスタグラム風写真共有アプリの要件定義書です。

---

## 1. アプリの概要

友人同士で旅行や日常の写真をシェアし合うための、シンプルで使いやすい写真共有Webアプリケーションです。FlaskとPeeweeを組み合わせ、基礎的なCRUD操作や認証機能をスモールステップで学びながら実装します。

## 2. 想定ユーザー

* 友人同士や身近なグループ内で、写真や短いコメントを通じて日常を共有したい人
* アプリへの投稿はログイン済みのユーザーのみが行える仕様とします。

## 3. 必須機能（小さく分割した構成）

初学者が段階的に実装できるよう、機能を小さく分けています。

1. **ユーザー管理機能**
* **ユーザー登録**: 新規ユーザーを作成する（IDやパスワードの設定）。
* **ログイン・ログアウト**: `Flask-Login` を使用して、安全にセッション管理を行う。


2. **写真投稿機能**
* **投稿フォーム**: 写真ファイル（1枚）と短いキャプション（テキスト）を入力して送信できる。
* **画像保存**: アップロードされた画像は、ローカルサーバーの `static/uploads` フォルダへ保存する。


3. **投稿一覧表示機能（タイムライン）**
* 投稿された写真とキャプション、投稿者名、投稿日時をタイムライン形式で一覧表示する。
* Bootstrapを活用し、スマートフォンからでも見やすいデザインにする。


4. **「いいね」機能**
* ログインしているユーザーが、各投稿に対して「いいね」を押せる（1人1回まで）。



## 4. 余裕があれば追加する機能

* 投稿に対するコメント機能（※検索やフォロー機能は今回のスコープ外とします）

## 5. 非機能要件

* **データベース**: SQLite（Peeweeを使用し、手軽にファイルとして管理）
* **デザイン/UI**: Bootstrap を適用し、レスポンシブ（スマホ・PC対応）なレイアウトにする
* **ファイルストレージ**: ローカルストレージ（`static/uploads`）

## 6. 実装時に注意すべきこと

* **機能を1つずつ確実に動かす**: まずは「データベース接続・ユーザー登録」、次に「ログイン」、その次に「写真投稿と一覧」というように、小さな単位で動作確認を行いながら進めること。
* **画像アップロードの不備対策**: フォームで画像が選択されていなかった場合や、許可されていないファイル形式の場合のエラーハンドリングをシンプルに意識すること。
* **パスワードの安全な取扱い**: パスワードを生のテキストで保存せず、必ずハッシュ化してデータベースに保存すること（ライブラリの機能を活用）。
