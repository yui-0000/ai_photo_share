# ルーティング設計書

Flaskのビュー関数とURL、HTTPメソッド、対応する画面のマッピング一覧です。

| URLパス | HTTPメソッド | ビュー関数名（目安） | 関連画面 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `/` | `GET` | `index` | 投稿一覧画面 | データベースからすべての投稿を新しい順に取得し、タイムラインを表示する。 |
| `/register` | `GET`, `POST` | `register` | ユーザー登録画面 | `GET`は登録フォームを表示、`POST`は入力されたデータを受け取り、パスワードをハッシュ化してDBに保存する。 |
| `/login` | `GET`, `POST` | `login` | ログイン画面 | `GET`はログインフォームを表示、`POST`は認証を行い、`Flask-Login`でセッションを開始する。 |
| `/logout` | `GET` | `logout` | （なし） | ログアウト処理を実行し、トップ画面（`/`）へリダイレクトする。 |
| `/posts/new` | `GET`, `POST` | `create_post` | 投稿作成画面 | `GET`は投稿フォームを表示。`POST`は画像ファイルを `static/uploads` に保存し、データベースに投稿データを登録して詳細画面へリダイレクトする（**要ログイン**）。 |
| `/posts/<int:post_id>` | `GET` | `post_detail` | 投稿詳細画面 | 指定された `post_id` の投稿データを取得し、詳細画面を表示する。 |
| `/posts/<int:post_id>/like` | `POST` | `like_post` | （なし） | 非同期通信（Fetch API）を受け取り、指定した投稿の「いいね」カウントを増やしてJSONで結果を返す（**要ログイン**）。 |
