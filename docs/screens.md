# 画面設計書

## 画面一覧と概要

| 画面名 | URL | ログイン要否 | 使用テンプレート名 | 目的・概要 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 投稿一覧（タイムライン）** | `/` | 不要（公開） | `index.html` | 投稿された写真とキャプションを一覧（タイムライン形式）で表示する。 |
| **2. ユーザー登録画面** | `/register` | 不要 | `register.html` | 新規ユーザーのアカウントを作成する。 |
| **3. ログイン画面** | `/login` | 不要 | `login.html` | アプリにログインするための認証フォームを表示する。 |
| **4. 投稿作成画面** | `/posts/new` | **必要** | `create_post.html` | 写真1枚とキャプションを入力して新しい投稿を作成する。 |
| **5. 投稿詳細画面** | `/posts/<int:post_id>` | 不要（公開） | `post_detail.html` | 特定の1件の投稿を大きく表示し、「いいね」機能を提供する。 |

---

## 各画面の詳細と画面遷移

### 1. 投稿一覧（タイムライン）画面
*   **URL**: `/`
*   **テンプレート**: `index.html`
*   **主な要素**: ヘッダー（ナビゲーション）、投稿カード一覧（投稿者名、日時、写真、キャプション、いいね数）
*   **画面遷移**:
    *   ヘッダーの「ユーザー登録」「ログイン」から各認証画面へ
    *   ヘッダーの「投稿する」から投稿作成画面へ（※要ログイン）
    *   投稿の画像や詳細リンクをクリックして「投稿詳細画面」へ

### 2. ユーザー登録画面
*   **URL**: `/register`
*   **テンプレート**: `register.html`
*   **主な要素**: ユーザー名入力欄、パスワード入力欄、登録ボタン
*   **画面遷移**:
    *   登録成功時 → ログイン画面または自動ログインして投稿一覧画面へ

### 3. ログイン画面
*   **URL**: `/login`
*   **テンプレート**: `login.html`
*   **主な要素**: ユーザー名入力欄、パスワード入力欄、ログインボタン
*   **画面遷移**:
    *   ログイン成功時 → 投稿一覧画面（`/`）へリダイレクト

### 4. 投稿作成画面
*   **URL**: `/posts/new`
*   **テンプレート**: `create_post.html`
*   **主な要素**: 画像ファイル選択フォーム、キャプション入力（テキストエリア）、投稿ボタン
*   **画面遷移**:
    *   投稿完了時 → 作成した投稿の「投稿詳細画面」へ直接ジャンプ

### 5. 投稿詳細画面
*   **URL**: `/posts/<int:post_id>`
*   **テンプレート**: `post_detail.html`
*   **主な要素**: 投稿者名、日時、大きな写真、キャプション、「いいね」ボタン（非同期）
*   **画面遷移**:
    *   ヘッダーのリンクや「戻る」ボタンから投稿一覧画面へ戻る
